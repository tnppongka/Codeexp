# ระบบจัดตารางเวร "ห้องยาสบปราบ"

## คู่มือการติดตั้งและใช้งาน

### สถาปัตยกรรม

ระบบนี้พัฒนาด้วย **Google Apps Script (GAS)** เป็น Web App ใช้ **Google Sheets** เป็น Database และส่งแจ้งเตือนผ่าน **LINE Messaging API**

---

## ขั้นตอนการติดตั้ง

### ขั้นตอนที่ 1: สร้าง Google Sheet

1. ไปที่ https://sheets.google.com
2. คลิก "สร้างสเปรดชีตใหม่" ตั้งชื่อว่า `ระบบจัดตารางเวร-ห้องยาสบปราบ`
3. คัดลอก **Spreadsheet ID** จาก URL (ส่วนที่อยู่ระหว่าง `/d/` และ `/edit`)
   - ตัวอย่าง: `https://docs.google.com/spreadsheets/d/1abcXYZ/edit` → ID คือ `1abcXYZ`

### ขั้นตอนที่ 2: เปิด Google Apps Script

1. จาก Google Sheet ที่สร้าง คลิกเมนู **ส่วนขยาย** > **Apps Script**
2. จะเปิดหน้าต่าง Apps Script Editor

### ขั้นตอนที่ 3: วางโค้ด Backend (Code.gs)

1. ลบโค้ดทั้งหมดในไฟล์ `Code.gs` (ฟังก์ชัน myFunction)
2. คัดลอกโค้ดทั้งหมดจากไฟล์ `gas/Code.gs` ไปวาง
3. **แก้ไขบรรทัดที่ 8**: ใส่ Spreadsheet ID ที่คัดลอกมา
   ```javascript
   const SPREADSHEET_ID = 'ใส่_ID_ที่นี่';
   ```

### ขั้นตอนที่ 4: สร้างฟังก์ชันเริ่มต้นชีท

1. ใน Apps Script Editor เลือกฟังก์ชัน `initializeSheets` จาก dropdown
2. คลิกปุ่ม **Run** (▶️)
3. อนุญาตสิทธิ์ (Authorize) เมื่อถูกถาม
4. กลับไปตรวจสอบ Google Sheet — ควรเห็นชีทย่อยครบ 7 ชีท

### ขั้นตอนที่ 5: สร้าง Frontend (index.html)

1. ใน Apps Script Editor คลิก **+** (บวก) > **HTML**
2. ตั้งชื่อว่า `index` (ไม่ต้องเติม .html — ระบบจะเติมให้เอง)
3. ลบโค้ดตัวอย่างทั้งหมด
4. คัดลอกโค้ดทั้งหมดจากไฟล์ `gas/index.html` ไปวาง

### ขั้นตอนที่ 6: Deploy เป็น Web App

1. คลิกปุ่ม **Deploy** (ด้านบนขวา) > **New deployment**
2. เลือกประเภทเป็น **Web app**
3. ตั้งค่า:
   - Execute as: **Me** (อีเมลของคุณ)
   - Who has access: **Anyone** (หรือ Anyone with Google account)
4. คลิก **Deploy**
5. คัดลอก **Web App URL** — นี่คือ URL ที่ผู้ใช้จะเข้าใช้งาน

### ขั้นตอนที่ 7: ตั้งค่า LINE OA

1. เข้าระบบด้วย Admin (ชื่อ: Admin, รหัสผ่าน: admin1234)
2. ไปที่เมนู **ตั้งค่าข้อมูล** > แท็บ **ตั้งค่าระบบ**
3. ใส่ **LINE Channel Access Token** ของ LINE OA
4. ใส่ **LINE Target ID** (Group ID หรือ User ID ที่ต้องการให้ส่งแจ้งเตือน)
5. คลิก **บันทึกการตั้งค่า**

### ขั้นตอนที่ 8: เพิ่มบุคลากร

1. ไปที่เมนู **ตั้งค่าข้อมูล** > แท็บ **บุคลากร**
2. คลิก **+ เพิ่มบุคลากร**
3. กรอกข้อมูล: ชื่อ-นามสกุล, ตำแหน่ง, อัตราค่าจ้าง/ชม., LINE User ID, รหัสผ่าน
4. เลือก **เป็น Admin** สำหรับผู้ดูแลระบบ

## การใช้งาน PWA (ติดตั้งบนมือถือ)

### Android (Chrome)
1. เปิด Web App URL ใน Chrome
2. คลิกเมนู (3 จุด) > **เพิ่มไปที่หน้าจอหลัก** หรือ **Install App**
3. ไอคอนจะปรากฏบนหน้าจอหลัก — ใช้งานได้เหมือนแอปปกติ

### iOS (Safari)
1. เปิด Web App URL ใน Safari
2. คลิกปุ่ม Share (รูปลูกศรขึ้น) > **Add to Home Screen**
3. ตั้งชื่อ แล้วคลิก Add

### Desktop
1. เปิด Web App URL ใน Chrome/Edge
2. จะมีไอคอนติดตั้งปรากฏที่ address bar — คลิกเพื่อติดตั้ง

## เมนูการใช้งาน

### 1. ฉันจะจองเวร
- เลือกเดือน/ปี (พ.ศ.) จาก Dropdown
- ดูปฏิทินแบบเต็มหน้าจอ พร้อมแสดงวันหยุดและนักขัตฤกษ์
- คลิกวันที่ว่างเพื่อจอง → เลือกประเภทเวร → ยืนยัน
- ระบบตรวจสอบการจองซ้อนอัตโนมัติ
- ปุ่ม "พิมพ์ปฏิทิน" สำหรับพิมพ์ออกทางเครื่องพิมพ์

### 2. ตั้งค่าข้อมูล
- **บุคลากร**: เพิ่ม/แก้ไข/ลบ รายชื่อ + ตำแหน่ง + อัตราค่าจ้าง + LINE ID
- **ประเภทเวร**: ดูและแก้ไขประเภทเวร + อัตราคูณ + แจ้งเตือน
- **การแจ้งเตือน**: ตั้งค่าว่า User ใดต้องการแจ้งเตือนประเภทเวรใด
- **วันหยุด**: จัดการวันหยุดนักขัตฤกษ์ไทย
- **ตั้งค่าระบบ**: LINE Token, Group ID, ชื่อหน่วยงาน

### 3. รายงาน
- ตารางเวรประจำเดือน (รูปแบบราชการ TH Sarabun A4)
- ตารางเวรเอกสาร
- เอกสารแนบเวรเอกสาร
- หลักฐานการจ่ายเงิน
- เวรฉันวันไหน (สรุปข้อมูลรายบุคคล)

### 4. วิเคราะห์ข้อมูล
- เลือกเดือน/ปี → เลือกบุคคลที่อยู่เวรเอกสาร
- ระบบแสดงตาราง: วันที่ | เวลา | รายละเอียดโครงการ | จำนวนผลงาน
- กระจายโครงการจากชีท egp อัตโนมัติ

## การอัปเดตโค้ด

เมื่อมีการแก้ไขโค้ด:
1. เปิด Apps Script Editor
2. วางโค้ดใหม่ทับไฟล์เดิม
3. คลิก **Deploy** > **Manage deployments** > แก้ไข (Edit) > เวอร์ชันใหม่ (New version) > **Deploy**
